# Arghya Kamal: Nexus

Build a premium, futuristic and highly animated personal portfolio website for “Arghya Kamal Dey”, a Computer Science & Engineering (Data Science) student at Kazi Nazrul University, Batch 2024–2028. Create the complete website in one go with a cinematic hero section featuring my name, “CSE (Data Science) Student”, university and batch. Use modern UI, advanced CSS, glassmorphism, gradients, glowing elements, smooth scrolling, scroll-reveal animations, hover/click animations, animated buttons, micro-interactions, parallax effects and smooth page transitions. Add About Me, Skills, Projects, Education, Achievements and Contact sections. Make project cards highly interactive with tech-stack badges, descriptions and demo/GitHub buttons. Use a premium dark futuristic aesthetic, excellent typography, responsive design and mobile support. Make every section visually engaging but clean and professional. Do not use generic template-looking designs. Build everything in one go and optimize the implementation to minimize unnecessary dependencies.
